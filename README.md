## Sobre el proyecto

**FAE-AFtErclass** es una landing page creada para reunir recursos, actividades y espacios de conexión para estudiantes de Administración de Empresas. La experiencia organiza contenidos por semestres mediante nueve *Rounds* y facilita el acceso a la comunidad y sus recursos.

> Proyecto estudiantil independiente; no representa oficialmente a la Universidad Externado de Colombia ni está patrocinado por ella.

## Funcionalidades

- **Rounds académicos:** contenido organizado en nueve etapas asociadas al recorrido de la carrera.
- **Comunidad y recursos:** acceso a los canales comunitarios y materiales compartidos.
- **Calendario:** acceso al calendario semestral.
- **Sugerencias y contacto:** enlaces para compartir ideas y comunicarse con el equipo.
- **Diseño adaptable:** navegación pensada para escritorio y dispositivos móviles.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- SVG para recursos gráficos

El proyecto es estático y no requiere un proceso de compilación.

## Ejecutar localmente

1. Clona o descarga este repositorio.
2. Abre una terminal dentro de la carpeta del proyecto.
3. Ejecuta:

```bash
python -m http.server 8080
```

4. Abre [http://localhost:8080](http://localhost:8080).

También puedes abrir `index.html` directamente en el navegador; para probar formularios y navegación, se recomienda usar un servidor local.

## Estructura

```

├── app.js       # Interacciones y contenido dinámico
├── assets/      # Recursos gráficos
```

## Estado y alcance

Este repositorio contiene el código fuente de la landing page. Los enlaces a servicios externos, como Discord o Google Drive, dependen de la disponibilidad y configuración de esos servicios.
